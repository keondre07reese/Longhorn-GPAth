# Longhorn GPAth

A GPA planning tool designed for UT Austin students to model semester outcomes and reach their target academic goals.

## Key Features
- Calculate semester and cumulative GPA
- Track GPA changes based on course inputs
- Target GPA forecasting
- Grade strategy recommendations

## Purpose/Problem
Students often struggle to understand how their semester performance impacts their cumulative GPA. This tool helps users plan ahead by simulating different grade scenarios.
